== Health and endpoints

Every service exposes `/actuator/health` (open, for probes) and `/actuator/metrics` (requires the
`admin` role). The gateway does not route `/actuator`; call each service on its own port.

Planned: tracing, dashboards and alert rules (s10); container images, one-command stack and
Kubernetes manifests (s11).
