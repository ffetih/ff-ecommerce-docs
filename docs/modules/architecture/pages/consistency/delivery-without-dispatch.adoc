====
* The dispatch event can only be missing because it was dead-lettered itself.
* Accepting the delivery would show a delivered order whose stock was never committed in catalog.
* Fix: delivery is only accepted from SHIPPED; otherwise the event is refused and goes to the dead-letter topic next to the dispatch it depends on, where both can be replayed in order.
