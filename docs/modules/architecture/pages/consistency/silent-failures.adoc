====
* An outbox stuck behind a failing message keeps other services from hearing about changes.
* A dead-lettered record is a saga step that did not happen; nothing retries it.
* Fix: `outbox.pending`, `outbox.oldest.pending.age` and `messaging.dead.letters{topic, exception}` in every service using the messaging module.
* A failed read reports NaN, not a reassuring zero; a dead letter is counted only after the dead-letter topic has taken it.
