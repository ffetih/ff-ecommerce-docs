[NOTE]
.Facts to build on (remove when the story is written)
====
* The inbox recognises a redelivered event only while it remembers the event id.
* Fix: topics keep events 7 days, set explicitly; the inbox keeps ids 30 days; a service whose inbox retention is not longer than its topic retention does not start.
* Expired ids are deleted hourly, in batches.
====
